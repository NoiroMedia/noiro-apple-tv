# Noiro Apple TV

A planned free, open-source media app for Apple TV, with navigation designed for the Siri Remote.

**Status: planning. This repository currently contains the project plan. No app implementation or installable release is available yet.**

Initial development focuses on [Noiro Android TV](https://github.com/NoiroMedia/noiro-android-tv). Apple TV development follows once that foundation is ready.

## Planned foundation

- Media browsing and search
- Video playback and subtitles
- Watchlist and Continue Watching

## Get involved

Use Issues to discuss Apple TV needs and feature ideas. Discuss larger changes before starting a pull request.

Build instructions, licensing details and release information will be added before implementation is published.
